# Spec-Driven Development

## Workflow

1. **Understand Requirements**: Clarify problem statement, target users, and constraints.
2. **Draft Technical Spec**: Outline data structures, user workflows, API contracts, error cases, and UI requirements.
3. **Review & Align**: Align with stakeholders/users on the spec.
4. **Pass to Implementation**: Use spec as single source of truth for planning (`/plan`) and building (`/build`).
