# Idea Refine

## Steps

1. **Clarify Goals & Use Cases**: What problem does this solve for the user?
2. **Deconstruct Scope**: Identify MVP requirements vs optional enhancements.
3. **Identify Technical Constraints**: Storage, performance, UI layout, browser support.
4. **Draft Feature Summary**: Concise spec ready for `/plan` or implementation.
