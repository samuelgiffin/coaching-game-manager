# Frontend UI Engineering

## Key Standards

1. **Rich Aesthetics**: Vibrant, curated color palettes, smooth transitions, modern typography, glassmorphism, dynamic micro-interactions.
2. **Accessibility (WCAG 2.1 AA)**: Keyboard focusable, screen reader friendly (`aria-label`, semantic tags), sufficient contrast ratios (≥4.5:1).
3. **Responsive & Fluid Layouts**: CSS Grid/Flexbox, container queries, mobile touch targets ≥44x44px.
4. **State Management**: Localize state, avoid mutating DOM directly, isolate side-effects.
