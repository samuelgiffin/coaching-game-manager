# Code Simplification

## Principles

- **Clarity Over Cleverness**: Code is read much more often than written.
- **Flatten Nesting**: Use early returns (guard clauses) to reduce indentation depth.
- **Delete Dead Code**: Remove unused functions, dead branches, and commented-out snippets.
- **Reduce State Complexity**: Prefer derived state over duplicated synchronized state.
