# Constraint-Driven Development

## Principles

- **Define Once, Enforce Everywhere**: State performance budgets, tech stack boundaries, and code style rules explicitly before writing feature code.
- **Fail Early on Violation**: Automated lints, type checks, and build scripts enforce constraints.
