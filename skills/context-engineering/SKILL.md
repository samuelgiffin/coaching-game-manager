# Context Engineering

## Principles

- **Curate Before Querying**: Read key interfaces and definitions before sweeping whole directories.
- **Keep History Clean**: Avoid repetitive non-informative loops or verbose output dumps.
- **Reference Ground Truth**: Use concrete source files rather than memory or assumptions.
