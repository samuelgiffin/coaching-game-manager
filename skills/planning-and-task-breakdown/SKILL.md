# Planning and Task Breakdown

## Principles

- Break features down into self-contained tasks (15-30 minutes of work each).
- Order tasks by dependency hierarchy (foundation/models -> core logic -> API/DOM -> UI polish).
- Every task includes clear verification criteria.
