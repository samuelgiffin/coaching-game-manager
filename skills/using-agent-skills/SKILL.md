# Using Agent Skills

## Core Rule

Invoke relevant skills BEFORE executing implementation actions. If a skill applies to your task, you MUST use it.

## Lifecycle Mapping

- **DEFINE** → `spec-driven-development`
- **PLAN** → `planning-and-task-breakdown`
- **BUILD** → `incremental-implementation` + `test-driven-development`
- **VERIFY** → `debugging-and-error-recovery` + `browser-testing-with-devtools`
- **REVIEW** → `code-review-and-quality` + `security-and-hardening`
- **SHIP** → `shipping-and-launch`
