# Definition of Done

Standard quality gate checklist before completing any task or PR:

- [ ] **Functional**: Spec requirements are met completely.
- [ ] **Tests**: Unit and integration tests written and passing.
- [ ] **Code Quality**: Clean, well-structured, no dead code or unhandled promises.
- [ ] **Security**: Inputs validated, zero XSS/injection vulnerabilities.
- [ ] **Performance**: Zero main-thread blocking, fast load times.
- [ ] **Accessibility**: Keyboard navigable, valid contrast, screen reader ready.
- [ ] **Verification**: Verified at runtime (browser/terminal evidence gathered).
